
# 🧠 Mini Curso de Versionamento de Código

## 📚 Objetivos do Curso

- Entender o que é controle de versão e por que utilizá-lo
- Aprender os principais comandos do Git
- Praticar o uso do Git em projetos reais
- Compreender o fluxo de trabalho com repositórios locais e remotos (GitHub)

---

## 🧩 Estrutura do Curso

O curso está dividido nos seguintes módulos:

1. **Introdução ao Controle de Versão**
    - O que é versionamento de código
   - Benefícios e casos de uso

2. **Instalação e Configuração do Git**
   - Instalação em diferentes sistemas operacionais
   - Configuração inicial do Git

3. **Comandos Básicos do Git**
   - `git add`, `git commit`, `git status`, `git log`
   - Navegação por versões

4. **Trabalhando com Repositórios Remotos**
   - Criando conta no GitHub
   - `git push`, `git pull`, `git clone`

5. **Branches e Colaboração**
   - Criando e gerenciando branches
   - Merge e resolução de conflitos
   - Fluxos de trabalho colaborativos (ex: Git Flow, GitHub Flow)

6. **Desafios e Projetos Práticos**
   - Exercícios de fixação
   - Mini projeto final com versionamento completo
