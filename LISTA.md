# 🚀 Comandos Git Essenciais

Este guia apresenta os comandos fundamentais do Git para iniciar e gerenciar projetos versionados com eficiência.

---

## 📥 Clonar Repositório

`git clone <url-do-repositorio>`

Copia o projeto remoto (ex: GitHub) para sua máquina local.

---

## 📊 Verificar Status

`git status`

Exibe os arquivos modificados, adicionados ou não rastreados no repositório local.

---

## 📜 Histórico de Commits

`git log`

Mostra o histórico completo de commits com autor, data e mensagens.

---

## ➕ Adicionar Arquivos

`git add <nome-do-arquivo>`

Adiciona um arquivo específico à área de staging.

`git add .`

Adiciona **todos** os arquivos modificados à área de staging.

---

## ✅ Criar Commit

`git commit -m "mensagem explicativa"`

Registra as alterações adicionadas com uma mensagem descritiva.

---

## 🌿 Gerenciar Branches

`git branch`

Lista todas as branches existentes.

`git branch <nome-da-branch>`

Cria uma nova branch.

`git checkout <nome-da-branch>`

Muda para a branch especificada.

---

## 📤 Enviar para o Repositório Remoto

`git push`

Envia os commits locais para o repositório remoto.

---

## 📥 Atualizar Repositório Local

`git pull`

Baixa e integra as últimas alterações do repositório remoto.

---
